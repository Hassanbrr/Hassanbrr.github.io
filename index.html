01 — About

Precision that stays in the code

More than two years living inside clean architectures and real production systems, where every layer has a clear responsibility and nothing is written by accident.

I'm Hassan Bahmandar, a backend developer and co-founder of the software studio BLG Tech. My core focus is ASP.NET Core, C# and Entity Framework Core, and Clean Architecture with Repository and CQRS patterns is the backbone of every project I build.

Alongside the backend, I build admin interfaces with Blazor Server, and deploy projects on Windows VPS/IIS behind ArvanCloud CDN — working within the real constraints of Iran's internet infrastructure, from filtering to local payment gateways.

I like solving real business problems: from multi-layer discount engines to infrastructure and payment-gateway issues. To me, clean code means a system you can still extend tomorrow without fear.
